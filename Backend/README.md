# backend

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run dev
```

After changing chunking or embedding settings, start the API and run
`bun run reindex` in a second terminal to regenerate stored chunks.

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
